# The main types of ViewPanel

The main types of ViewPanel in @designable/react are:

DESIGNABLE: The main visual design canvas for drag-and-drop and editing.
JSONTREE: Shows the JSON schema or tree structure of the current design.
PREVIEW: Renders a live preview of the form or component as it would appear to end users.
MARKUP: Shows the generated code or markup (e.g., JSX, HTML) for the current design.
